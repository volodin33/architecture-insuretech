# Задача 3

## Проблемы и риски

### 1. Синхронная зависимость

ins-product-aggregator является единой точкой отказа. Если он недоступен оба потребителя получают ошибку. 

### 2. Избыточные запросы

core-app опрашивает агрегатор каждые 15 минут вне зависимости от того, изменились ли данные. Большинство запросов возвращают те же данные — ресурсы тратятся впустую. 
### 3. Блокировка потоков

Синхронный вызов удерживает поток core-app или ins-comp-settlement на всё время ожидания ответа от агрегатора. 

### 4. Нет гарантий доставки обновлений

При ошибке в момент ответа агрегатора потребитель либо не получает данные, либо получает устаревшие. Нет механизма повтора или подтверждения получения

### 5. Жёсткая связанность

core-app и ins-comp-settlement напрямую зависят от контракта REST API агрегатора.
